## 1. 目标与边界

前提：飞机已经进入能够识别装甲板的区域。装甲板水平安装、正面朝上，OpenMV 固定下视。

目标：飞机到达装甲板物理中心沿重力方向的正上方，并持续保持 1.0 米垂直间距。

1.0 米按机体参考点到装甲板物理中心的垂直距离计算，包含相机安装位置补偿。它不是相机光轴深度，也不是飞机离地高度。

本次包含：四端点检测、相对三维位姿估计、短时预测、坐标转换、视觉导航外环、必要的 PX4 通信及离线验证。

本次不包含：起飞、粗导航、基地离地高度测量、场地绝对坐标建图、障碍物路径规划或撞击动作。

运行要求：H7 Plus 标准固件与 MicroPython，不编译或烧录定制 C/C++ 固件。起飞、解锁和进入导航模式由操作者或已有任务流程负责，本程序不自动执行。

## 2. 已确认的设计约束

- 同一次灯条检测同时服务四点测量、中心显示和目标关联，不运行两套完整图像检测。
- 参考同济传统检测的几何组织顺序：确定左右灯条，再确定上下端点。
- 四点顺序固定为：1 左上、2 右上、3 右下、4 左下。
- 首版使用正常观察范围内的图像几何建立对应，暂不要求极端倒置视角下的固定物理身份识别。
- 标靶局部坐标原点设在物理中心。四个模型点必须与图像点逐项对应，并使用真实米制尺寸。
- 只完成相对任务时，不要求输入标靶在场地坐标系中的位置或基地离地高度。
- 保留现有连续确认、目标关联和短时丢失逻辑作为基线，区分真实观测与预测。
- 调试画面以一个物理中心定位十字为主，区分测量和预测状态。

```text
1 左上 ───── 2 右上
  │             │
4 左下 ───── 3 右下
```

## 4. 处理流程

```text
采图
  → 灯条检测与配对
  → 有序四端点与质量检查
  → 平面位姿估计
  → 相机系中心位置
  → 安装外参转换到机体系
  → 飞控姿态转换到重力对齐坐标
  → 相对状态更新或短时预测
  → 水平偏差与垂直间距误差
  → 有界速度参考
  → PX4 内部控制执行
```

观测模式只计算、显示和记录结果；导航参考发送需明确启用，并满足飞控模式及状态条件。

## 5. 算法与行为

### 5.1 灯条端点与中心

- 保留已有亮斑筛选、判色、灯条配对和去重基础。
- 使用标准固件的原生灯条几何接口取得中心线端点，避免在 MicroPython 中重复实现完整轮廓拟合。
- 输出同一帧的有序四点，不把独立平滑或预测的四个点冒充本帧刚体观测。
- 仅对最终选中目标进行位姿解算；缓存可复用几何量。
- 检查点间距、点序、目标面积和明显退化情况。端点质量不足时，可保留中心跟踪，但不据此生成新的可信三维测量。

### 5.2 平面位姿估计

采用“单应矩阵初始化＋有界重投影优化”的固定四点平面 PnP 路线，使用纯 MicroPython 小规模运算。

步骤：四点去畸变与归一化 → 平面单应求解 → 位姿初始化 → 有限次重投影优化 → 质量检查。

选择原因：目标四点共面且数量固定，便于限制计算规模和最坏耗时；无需移植桌面 OpenCV 运行环境。同济用于参考端点定义和排列，板上求解器不预设具有桌面 IPPE 相同的精度和性能。

输出包括：相机系中心位置、旋转结果、重投影误差、测量时间与有效性。内部求解仍保留旋转，首项验收重点为中心三维位置。

已知端点真实尺寸提供米制尺度。标靶局部平面坐标为零只表示模型坐标选择，不表示标靶安装在地面。

对负深度、退化、数值异常或明显不一致的结果拒绝更新。平面位姿可能存在歧义，质量判断不能只依赖一个较小的重投影误差；结合水平标靶先验、姿态和历史一致性检查。

### 5.3 坐标转换与高度

相机坐标约定：右、下、光轴前。机体系采用 FRD：前、右、下。

相机系中心位置为 p_C，机体系中心位置为：

```text
p_B = R_BC × p_C + t_BC
```

其中 R_BC 将相机轴表达转换为机体轴表达；t_BC 是相机光心在机体系中的位置。

再利用图像时刻对应的飞控姿态，得到重力对齐坐标中的目标相对位置。目标低于机体时，向下的垂直间距为正，期望值为 1.0 米。

相机安装外参未确认、姿态过期或时间关系不可靠时，不能把结果宣称为可信的机体垂直间距。

### 5.4 视觉导航外环

- 根据水平偏差及“实际垂直间距减去 1.0 米”形成相对位置误差。
- 使用位置误差比例外环生成速度参考，分别设置水平、垂直增益。
- 对速度及速度变化施加限制，减少观测修正引起的指令突变。
- 使用 PX4 支持的速度参考接口；姿态和速度内环继续由 PX4 执行。
- 满足水平和垂直到位容差并持续达到设定时间后，进入保持状态；保持阶段继续接受视觉修正。
- 保持进入时的航向，不增加相对装甲板方向的航向对齐任务。
- 飞控本地坐标用于表达参考和状态，不要求人工输入标靶场地绝对坐标。

### 5.5 连续性与丢失

- 以现有连续 3 帧确认、最多 4 帧短时丢失为初版基线。
- 真实测量可用时更新相对状态；短时缺测时利用最近目标观测和飞机运动状态进行预测。
- 预测保留来源及观测年龄，不重置为新的真实测量时间。
- 恢复识别后进行一致性检查和平滑校正。
- 超过可用边界后平滑退出目标接近，交由预先约定且满足飞控状态条件的保持或失效处置；不无限沿历史目标继续运动。
- 四帧在不同帧率下代表不同时间，因此同时记录实际时间；时间门限应在验证后明确。

### 5.6 飞控状态与通信

参考并选择性复用 visual_odometry 中已有的连接发现、姿态接收、时间同步和状态缓存基础，补充导航所需的速度与健康状态。

现有 LANDING_TARGET 属于目标观测输出，不能直接等同于导航速度指令。导航发送、模式识别、目标系统身份及超时处理需分别实现和验证。

速度参考接口要求 PX4 具有有效的速度估计。本次不实现粗导航，但视觉阶段仍需保留飞控必要的状态估计来源。若 MTF-02 为其提供速度和高度观测，应继续服务状态估计；MTF-02 向地测距不替代 PnP 的标靶距离。

以项目声明的 PX4 1.17 文档作为接口检查起点，实机版本和融合状态仍待确认。

## 7. 性能与显示

- 一次检测复用灯条信息，只对选中的目标解算。
- 限制迭代次数，重用缓存，减少循环内对象分配和重复几何计算。
- 默认只画物理中心定位十字；测量与预测使用可区分状态。
- 在原始图像上绘制时，中心投影使用与显示图像一致的畸变模型。
- 低频输出 FPS、解算耗时、观测年龄、状态与质量，避免逐帧大量打印。
- 统计平均及峰值耗时。帧率以 H7 Plus 实测报告，不提前承诺固定数值。

## 8. 实施顺序与验证

1. 建立独立目录结构及配置，完成四端点检测和观测模式。
2. 完成平面位姿求解及中心投影，以独立合成投影验证位置恢复。
3. 验证安装外参与重力方向转换，再接入飞控姿态和速度状态。
4. 完成相对状态管理与导航外环，先进行离线闭环仿真。
5. 验证 MAVLink 编解码、状态超时、导航发送条件和运行模式。
6. 整理板上测量、性能测试与后续实机联调步骤，交付代码和验证记录。

重点验证：

- 已知三维位姿投影后的四点能否恢复中心位置，检查尺度与坐标方向。
- 正视、倾斜、像素噪声、小目标、错误点序和退化情况下的结果及拒绝行为。
- 相机倾斜和安装偏移存在时，仍正确计算重力方向间距。
- 改变标靶离地高度、不改变相对几何时，输出的相对位置保持一致。
- 闭环仿真能否收敛到水平居中、垂直间距 1 米并保持。
- 观测延迟、短时丢帧、恢复识别及完全丢失时的连续性。
- 通信报文、时间关系、输入状态过期和飞控模式条件。

不默认安装新依赖。优先使用现有环境；已有 OpenCV 时可作独立对照基准。板上 FPS、真实定位误差和实际飞行稳定性需分别实测，离线验证不能替代这些结果。
